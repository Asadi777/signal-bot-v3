### Open-book status & allowed materials — IMPORTANT, partially uncertain
There are **two different exams** people conflate; keep them separate:

1. **Red Seal / SkilledTradesBC Construction Electrician certifying exam** (the one for the Red Seal):
   - Red Seal exams are **generally described as closed-book**, BUT for electrical trades a
     **Canadian Electrical Code book is used/provided** for code-lookup questions. Public sources
     **conflict** on whether the code book is supplied at the exam vs. you bring your own, and on
     how "open" it is. **This is the single biggest unresolved point — verify directly with
     SkilledTradesBC** (1-866-660-6011 / portal). See "Uncertain/Conflicting" below.

2. **Technical Safety BC (TSBC) Electrical FSR exams** (Field Safety Representative — a *different*
   credential, needed to pull permits / supervise, not the Red Seal). These are **open-book,
   bring-your-own-clean-book**, with explicit marking rules:
   - You **must provide your own** current reference materials (BC Electrical Code / CSA C22.1,
     Safety Standards Act, Electrical Safety Regulation, etc.).
   - **Allowed markings:** highlighting, cross-referencing notes, tabs/flags marking sections,
     clarifying notes for a legal/technical term.
   - **Prohibited:** pages with **formulas, worked examples, or calculations** written in — these
     **must be removed before the exam**.
   - **Not allowed:** the **CEC Handbook** ("An explanation of the rules") and the **CEC Pocket
     Reference**.
   - Source (via snippet): https://www.technicalsafetybc.ca/technologies/electrical/electrical-fsr-certification/electrical-examination-reference-material-list

> The "clean/unmarked code book" rules a candidate hears about most often are the **TSBC FSR**
> rules above. Do not assume they are identical to the Red Seal certifying-exam rules.

## 3. Required code book (you must own this regardless)

- **2024 Canadian Electrical Code, Part I, 26th edition — CSA C22.1:24** (or the BC-specific
  **BC Electrical Code 2024**, which is the CEC plus BC amendments). Available spiral-bound.
  - CSA: https://www.csagroup.org/store/product/CSA_C22.1:24/
  - Amazon.ca listing: https://www.amazon.ca/2024-Canadian-Electrical-Code-26th/dp/1488342520
  - This is **the** reference the exam is built around — every serious prep product references it.

## 5. EXCLUDE / label — NEC (US) products (do NOT use for the BC/Canadian exam)

- **"NEC Electrical Exam by Dakota"** app — US National Electrical Code. EXCLUDE.
- Any "Journeyman Electrician" practice test referencing **NEC** (e.g., Mometrix journeyman test) — US.
- Generic "Construction Electrician practice exam" Amazon titles that don't state **CEC/Canadian** —
  verify before trusting; many are NEC or AI-generated.
- Rule of thumb: if it doesn't say **Canadian Electrical Code / CEC / CSA C22.1 / Red Seal**, assume
  it may be US/NEC and exclude.

## 6. Uncertain / conflicting — VERIFY before relying

1. **Open-book vs closed-book for the actual Red Seal certifying exam.**
   - One reading: Red Seal exams are **closed-book**, but a **code book is provided** for electrical
     code questions.
   - Another reading: candidates **bring their own clean code book** (this is firmly true for the
     **TSBC FSR** exam, and may be getting cross-applied to the Red Seal exam).
   - **Action:** confirm with SkilledTradesBC whether a CEC book is supplied at the sitting or you
     bring your own, and the exact marking rules. This is the top item to verify.

2. **Exact allowed markings for the Red Seal exam's code book** — the detailed marking rules above
   (highlight OK, formulas/calcs must be removed, Handbook & Pocket Reference banned) are confirmed
   for **TSBC FSR**, **not confirmed** to be identical for the Red Seal certifying exam.

3. **Pass rate "~55–65%"** — appears only on commercial prep sites; **not an official figure**.

4. **Red Seal Occupational Standard year** — one snippet says BC IP exams aligned to the **2021
   RSOS**; prep content cites **2024 CEC**. These aren't contradictory (RSOS = task standard year;
   CEC 2024 = code edition tested), but worth confirming the current RSOS year on red-seal.ca.

5. **Costs marked "verify"** — CSA CEPE price, BCIT TELC 0105 tuition, and Centennial book
   price/edition came from blocked pages; figures above are estimates or absent. Confirm on source.

6. **Official pages that blocked direct fetch** (facts taken from search snippets only):
   SkilledTradesBC electrician-construction page, Red Seal exam-info page, CSA store product pages,
   BCIT TELC 0105 page, Technical Safety BC reference-material page.

## 7. Bottom line for a candidate

- **Buy/own:** 2024 Canadian Electrical Code, 26th ed (CSA C22.1:24) — non-negotiable.
- **Single most-recommended prep:** **Dakota Prep / "Canadian Electrical Exam Prep" app** (2,500+
  CEC-2024 questions, timed sims, AI tutor; $79/yr or $189 lifetime) — best modern value. For an
  authoritative second source, add the **CSA CEPE** official practice exam.
- **If you want a book:** Centennial College Press C&M Electrician prep (confirm 2024-CEC edition).
- **If you want in-person/BC refresher:** BCIT **TELC 0105** Electrical Red Seal Refresher.
- **Expect:** 100 multiple-choice questions, 4 hours, 70% to pass, 4 attempts (30-day wait between),
  built on the 2024 CEC. **Confirm the exam-day code-book policy with SkilledTradesBC.**
