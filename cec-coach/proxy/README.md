# اشتراکِ AI بدونِ دادنِ کلید — نصبِ پروکسی (Cloudflare Worker)

با این پروکسی، **کلیدِ Anthropicِ تو امن روی یک سرورِ رایگان می‌ماند** و چند نفر می‌توانند از بخشِ هوش مصنوعیِ اپ استفاده کنند **بدونِ دیدنِ کلید**. آن‌ها فقط یک **رمزِ دسترسی** دارند که تو خصوصی به‌شان می‌دهی. هزینه‌ی مصرفِ همه با توست (در پنلِ Anthropic می‌توانی سقفِ خرج بگذاری).

> ⏱️ کلِ کار ~۱۰ دقیقه و کاملاً رایگان است. هیچ کارتِ بانکی برای Cloudflare لازم نیست.

---

## گام ۱ — ساختِ Worker در Cloudflare
1. برو به <https://dash.cloudflare.com> و یک حساب بساز/وارد شو.
2. از منوی چپ: **Workers & Pages → Create → Create Worker**.
3. یک اسم بگذار (مثلاً `cec-ai`) و **Deploy** بزن.
4. روی **Edit code** بزن، کلِ محتوای فایلِ `worker.js` (کنارِ همین README) را کپی کن، جایگزینِ کدِ نمونه کن و **Deploy** بزن.
5. آدرسِ Worker را بردار — چیزی مثلِ `https://cec-ai.<your-name>.workers.dev`.

## گام ۲ — افزودنِ کلید و رمز (Settings → Variables)
در صفحه‌ی Workerت برو به **Settings → Variables and Secrets** و این‌ها را اضافه کن:

| نام | نوع | مقدار |
|--|--|--|
| `ANTHROPIC_API_KEY` | **Secret** | کلیدِ `sk-ant-…` خودت |
| `ACCESS_CODE` | **Secret** | یک رمزِ دلخواه (مثلاً `pbr-2026`) که به دانشجوها می‌دهی |
| `ALLOWED_ORIGINS` | Text | آدرسِ سایتِ اپ، مثلِ `https://asadi777.github.io` (اختیاری ولی توصیه‌شده) |
| `FORCE_MODEL` | Text | برای کنترلِ هزینه، مثلاً `claude-haiku-4-5` یا `claude-sonnet-4-6` (اختیاری) |
| `MAX_TOKENS_CAP` | Text | سقفِ توکن، مثلاً `2000` (اختیاری) |

بعد از افزودن، یک بار دیگر **Deploy** بزن تا اعمال شود.

## گام ۳ — وصل‌کردنِ اپ به پروکسی
دو راه:

**الف) ساده‌ترین (هر کاربر یک‌بار):** کاربر در اپ، **⚙️ Settings** را باز می‌کند و این دو فیلد را پر می‌کند:
- **Shared AI server URL** → همان آدرسِ `https://cec-ai.<name>.workers.dev`
- **Access code** → همان رمزی که به او داده‌ای

دیگر نیازی به کلیدِ شخصی نیست؛ AI روشن می‌شود.

**ب) راحت‌تر برای پخشِ گروهی (یک‌بار توسطِ تو):** آدرسِ Worker را در فایلِ `web/app.js` در خطِّ
```js
var PROXY_URL = ""; // ← آدرسِ Worker را اینجا بگذار
```
بگذار و push کن. آن‌وقت کاربران **فقط رمزِ دسترسی** را در Settings وارد می‌کنند (URL از قبل داخلِ اپ است).

---

## امنیت و هزینه — چند نکته‌ی مهم
- **رمز را داخلِ app.js نگذار.** رمز را فقط خصوصی (پیام/حضوری) به همان چند نفر بده. چون اپ عمومی است، اگر رمز در کد باشد قابلِ دیدن است.
- **سقفِ خرج بگذار:** در <https://console.anthropic.com> → Billing → Limits یک سقفِ ماهانه تعیین کن تا مصرف از کنترل خارج نشود.
- **مدلِ ارزان‌تر برای گروه:** با `FORCE_MODEL=claude-haiku-4-5` هزینه به‌شدت کم می‌شود (برای تدریس معمولاً کافی است).
- **محدودکردن به سایتِ خودت:** `ALLOWED_ORIGINS` جلوی استفاده‌ی سایت‌های دیگر از پروکسیِ تو را می‌گیرد.
- اگر رمز لو رفت، در Cloudflare مقدارِ `ACCESS_CODE` را عوض کن و دوباره Deploy بزن — همه‌ی رمزهای قدیمی باطل می‌شوند.

## تستِ سریع
بعد از نصب، در اپ یک سؤال از **AI Tutor** بپرس. اگر جواب آمد، پروکسی کار می‌کند. اگر «Wrong or missing access code» دیدی، رمز را در Settings درست وارد کن.
